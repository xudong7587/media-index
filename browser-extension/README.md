# MediaIndex 转存浏览器扩展

这是一个独立于 MediaIndex 容器运行的 Chrome / Edge Manifest V3 扩展。它会在 115、夸克资源分享页的官方转存操作旁加入“转存到 MediaIndex”；如果暂时识别不到官方按钮，则显示右下角悬浮入口。

扩展版本以 `manifest.json` 为唯一来源，并与同一仓库中的 MediaIndex 兼容基线同步维护。分享页窗口、工具栏弹窗、设置页和浏览器扩展管理页都会自动显示此版本。

扩展本身不需要放进 MediaIndex 容器。v0.7.8 与 MediaIndex v0.7.8 的直链契约 v2 配套，复用“输入网址下载”链路，并提供目的地模式与无副作用命名预览。发现旧后台时扩展会明确提示先更新并重启后台。

## 安装

1. 打开 Chrome 的 chrome://extensions 或 Edge 的 edge://extensions。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”，选中本 browser-extension 目录。
4. 打开扩展的“详细信息”或扩展弹窗，进入“扩展选项”。
5. 填写 MediaIndex 地址、用户名和密码，点击“授权并连接”。
6. 打开或刷新一个支持的分享页。

## 更新

从仓库下载或更新 `browser-extension` 目录后，在 `chrome://extensions` 或 `edge://extensions` 中点击本扩展卡片上的“重新加载/刷新”，再刷新已经打开的 115、夸克分享页。弹窗和转存窗口应显示 `v0.7.8`。本版本需要 MediaIndex 后台包含直链契约 v2 并完成重启；如果后台仍是旧契约，扩展会停止提交并给出明确的更新提示。

支持的分享链接：

- pan.quark.cn/s/* 和 www.pan.quark.cn/s/*
- share.115.com/*（115 旧版分享页）
- 115.com/s/* 和其子域
- 115cdn.com/s/* 和其子域

## 使用

在分享页点击“转存到 MediaIndex”后可选择两条链路：

- 云下载后整理：分享链接 → 云下载一级子目录 → MediaIndex 自动整理 → 正式媒体库。点击子目录会立即提交。
- 直接入正式媒体库：分享链接 → MediaIndex 默认命名 → 正式媒体库。该模式不依赖云下载整理器，需填写媒体名称。

填写媒体名称后可以先点击“生成默认命名预览”，查看正式媒体库路径和源文件名到目标文件名的映射；预览不会执行转存。云下载链路中的“转存完成后继续自动整理入库”可关闭，关闭后不会触发云下载整理、STRM 或 Emby 入库。

扩展提交当前分享网址、目的地模式、媒体名称和所选路径，处理范围与 MediaIndex 页面中的“输入网址下载”一致。115、夸克官网页面里临时勾选的文件不会额外同步到 MediaIndex。

也可以点击浏览器工具栏中的扩展图标，再选择“转存当前分享页”来打开同一个目录选择器。

## 安全说明

- 密码只用于当次登录请求，扩展不会把密码写入本地存储。
- 扩展只在本地保存 MediaIndex 地址和用户名；登录会话由 Chrome / Edge 的 Cookie 存储管理，不保存 Bearer token。
- 保存设置时才会请求访问所填 MediaIndex 源站的可选权限，实际授权范围是该地址的准确 origin。
- 后台 API 请求均携带浏览器管理的登录 Cookie，并且只发往已配置且已授权的 MediaIndex 地址。
- 建议对非本机 MediaIndex 使用有效 HTTPS。HTTP 只适合可信局域网或本机调试环境。
- “移除本机连接”会尝试退出 MediaIndex 会话，然后删除扩展保存的地址、用户名并撤销对应可选站点权限。

分享页中的按钮和目录选择器位于 Shadow DOM 内，样式与 115、夸克页面隔离。分享页只能触发扩展后台动作，不能直接读取扩展保存的连接信息。

## 对接接口

扩展使用以下 MediaIndex HTTP 接口：

- POST /api/auth/login
- POST /api/auth/logout
- GET /api/auth/me
- POST /api/transfers/direct-link/options
- POST /api/transfers/direct-link/rename-preview
- POST /api/transfers/direct-link

所有接口地址都相对于设置页中填写的 MediaIndex 地址；反向代理子路径会被保留。

## 快速验收

1. 在设置页连接测试 MediaIndex，确认显示“已连接”。
2. 打开支持的分享页，确认按钮出现在官方转存操作附近，或在右下角显示悬浮入口。
3. 点击按钮，确认能看到“云下载后整理”和“直接入正式媒体库”两条链路。
4. 填写媒体名称并生成默认命名预览，确认未直接提交任务。
5. 云下载已启用时点击一个一级子目录，确认提交成功。
6. 切换到直接入正式媒体库，确认空名称会阻止提交，填写名称后可以提交。
7. 从扩展弹窗点击“转存当前分享页”，确认可以打开同一个选择器。
