# MediaIndex 1.0.0

1.0.0 发布本地验收通过的新前端。页面沿用 MediaIndex Next 预览设计，接入现有后端，补齐设置、资源核对、转存和追更等操作。

## 页面和操作

- 媒体详情成为右侧工作区页面，保留侧栏导航，支持季度、分类、资源候选、授权目录、愿望单、追更和手动链接核对。各网盘分别显示结果与错误；刷新目录按名称保留选择，提交期间阻止重复执行。
- 链路节点默认展示名称和状态，点击展开说明。顶栏任务浮层、任务完整记录和计划任务编辑接入实际接口；缺失的历史节点显示“未记录”，不推算成功。
- 恢复通知、交互指令和云下载设置，补齐 Webhook、诊断授权、封面工坊、网盘目录、追更与愿望单调度等入口。保存失败保留输入和错误提示。
- 发现页切换流媒体平台只更新页内榜单，轮播保持页面节点；修正海报边线和阴影裁切。
- 调整手机上的媒体详情、STRM 三页签、目录选择和外观面板。圆角、原生下拉面板、Logo 和导航按钮使用统一外观参数。

## 兼容和范围

- 数据库结构、配置字段与环境变量定义不变，已有配置继续使用。
- 新增鉴权只读接口 `GET /api/transfers/{job_id}/workflow`，精确查询历史任务。查询不创建节点或启动任务；已有媒体级查询和执行接口保持兼容。
- 前端改用 `frontend/src/next/main.js` 入口；旧 React 源码仍保留，未作为当前页面入口打包。
- 正式源码和镜像不包含本地企业微信模拟器、沙箱配置、数据库或缓存。
- GitHub 工作流构建 amd64/arm64 镜像并发布 `latest`、`1.0.0` 和 `v1.0.0` 标签。NAS 由用户手动更新。

## 验证

完整 Python 回归 1485 项通过、2 项跳过，61 个子测试通过；前端 29 项回归、生产构建和浏览器扩展契约测试通过。已在本地浏览器验收主页面、任务、设置和 320/390/768px 响应布局；PR CI 作为合并门禁。

真实网盘转存、删除、STRM 生成、外部通知及 Emby 写入未在本轮发布检查中执行。相关自动化使用模拟接口；外部服务仍依赖用户现有授权与连接状态。

模块边界及逐项验收记录见 [FRONTEND-INTEGRATION.md](FRONTEND-INTEGRATION.md)。
