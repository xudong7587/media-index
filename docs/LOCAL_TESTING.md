# 本地测试沙箱

本地浏览器版是默认开发与人工验收环境。它与 NAS 数据隔离，只监听本机回环地址：前端 `http://127.0.0.1:5173/`，后端 `http://127.0.0.1:8000/openapi.json`。

## 启动

```powershell
.\scripts\start-local.ps1
```

脚本会保留并使用 `.tmp/local-055/` 下的 `runtime.env`、数据库、缓存及日志。该目录被 Git 忽略，不能提交其中的账号、令牌、Cookie 或数据库。

首次创建的配置默认关闭调度、自动同步、通知、企业微信和直链下载。需要测试 QAS、115、TMDB 等真实集成时，只在该 `runtime.env` 中按需填写；每次真实外部操作都需要作为单独的人工验收动作，不能因为本地沙箱而默认安全。

## 验收与升级

1. 普通 UI、接口、文案、响应式和大部分业务交互，先在本地版验收。
2. 只有用户明确要求部署到自用 NAS，或改动必须验证 NAS 路径、容器、HTTPS 反代、真实下载/通知/外部服务时，才走 NAS A1/A2。
3. 用户在本地或明确要求的 NAS 验收通过后说“发布 Git”，才进入 PR、CI、`main` 和 GitHub Release。

本地服务器是长期测试入口，不使用 `-test` 版本号，也不改变 GitHub 正式版本语义。
