# MediaIndex 1.0.1

修复 1.0.0 部署后发现的转存操作与页面问题。

## 资源获取与转存

- 发现页的分享资源按作品身份核验、命名后直接写入正式媒体库，不再选择云下载目录。普通链接下载与磁力下载保留原流程。
- 夸克、115 分别提供转存按钮，并恢复打开资源、复制分享链接和 PanSou 入口。底部支持一键转存两边；夸克有资源而 115 明确无资源时，可先存夸克再补齐 115。
- CD2 手动复制支持 115 → 夸克。完成后核对原生夸克的实际落盘文件，再继续 STRM 与 Emby 流程。OpenList 和自动补齐的方向保持原规则。

## 页面修复

- 调整返回按钮、分类选项间距和字号；分享复制使用短暂浮动提示。链接下载补齐返回按钮。
- 追更巡检设置横向显示，任务卡片使用整行宽度，目录选择改用文件夹图标。
- PanSou 排除关键词保留原值并可编辑，关闭编辑框拖动缩放；频道订阅新增全部开启、全部关闭。
- 调整任务中心三级菜单；媒体库使用整行宽度，播放会话可从概览打开独立窗口。
- 修复使用手册的章节切换和顶部入口；调整链路概览字体，窄屏连接图沿用宽屏曲线顺时针旋转 90°。
- 修复发现页 banner 在宽屏下重复平铺；移除侧栏独立深色图标，将 GitHub 入口移至右侧。

无需数据库迁移或新增环境变量。正式镜像提供 `latest`、`1.0.1`、`v1.0.1` 标签，支持 amd64 和 arm64；NAS 由用户手动更新。
