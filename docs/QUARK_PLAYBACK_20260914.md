# 夸克 STRM 播放修复

Primary Module：`strm`；必要跨模块依赖：`cloud` 的夸克客户端提供下载接口刷新后的认证请求头。没有数据库、配置或 STRM 令牌格式变更。回归覆盖既有 115 直连/转发、夸克 Range 与认证刷新；完整后端测试 1162 项及 43 个子测试通过。

用户生成 STRM 后，Emby 和绿联影视中心均无法播放。读取用户提供的播放入口返回 302，但跟随夸克 CDN 链接返回 HTTP 412：播放服务错误地将需要 Cookie、固定 User-Agent 和 Referer 的夸克下载链接当作免请求头直链。

夸克下载结果现在保留下载接口轮换后的 Cookie 及其请求头，播放服务使用已有流式转发链路保留 Range 和 Content-Range。认证信息仅用于服务端请求，不进入 STRM、播放器响应或重定向地址；夸克上游禁止跟随重定向。401/403/412 最多刷新一次链接和认证后重试。115 既有的可直连 302 行为保持原合同。

真实只读验证：用户指定的 `/strm/夸克测试/希望 (2026)` 中唯一视频为 `希望.2026.mp4`，大小 5,874,856,210 字节。修复后的本地播放 API 使用真实夸克客户端分别读取开头及结尾 1,024 字节，均返回 206、正确 Content-Range 和 proxy 模式；文件头具有 MP4 的 `ftypisom` 标识。测试仅替换本地资产令牌查询以指向用户指定文件，不修改用户实例数据库、STRM 或云端文件。

此验证证明实际影片分段读取成功，不等同于 Emby/绿联播放器端完整解码验收。部署更新后的播放服务后，已有有效 STRM 无需重新生成。夸克视频数据经 MediaIndex 转发，占用其所在主机的网络带宽。
