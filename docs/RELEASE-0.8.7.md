# MediaIndex v0.8.7

修复发现页和愿望单的 115 资源获取流程：

- 发现页携带媒体计划提交任务时，保留已验证的入口来源和云下载子目录，避免有效目录被误报为“所选保存目录已失效”。历史 `discovery` 来源兼容同一目录作用域校验。
- PanSou 中文查询已有标题、年份及季集证据匹配的磁力候选时，不再继续用英文名称重复检索。同次查询中的可用原生分享仍优先；错误年份或证据不足的候选不会提前结束搜索。
- 愿望单匹配到 115 磁力后，实际调用已有云下载提交与监控流程。提交后停止定时重复检查；监控核验成功后更新愿望单完成状态，失败或需要人工确认时保留待确认状态。

本次仅包含功能修复，不包含仍在本地调整的界面、外观与豆瓣榜单功能。API、数据库结构、配置和部署方式保持兼容，无需迁移。未修改或部署 NAS。
