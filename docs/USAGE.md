# MediaIndex 使用手册

MediaIndex 是面向个人 NAS 的媒体发现、多网盘转存、愿望单、智能追更和通知交互控制台。它不提供资源，只把你自行配置的 TMDB、PanSou、QAS、115、OpenList 和通知渠道串成一套可追溯的自动化流程。

## 1. 部署方式

### 1.1 只部署 MediaIndex

1. 新建部署目录并下载仓库根目录的 `docker-compose.yaml`。
2. 修改 `MEDIA_USER` 和 `MEDIA_PASS`，不要使用示例密码。
3. 执行：

   ```bash
   docker compose up -d
   ```

4. 访问 `http://NAS_IP:38000`。
5. 登录后进入 **设置**，填写已有 TMDB、PanSou、QAS、115、OpenList 和通知渠道配置。

如果 PanSou、QAS 或 OpenList 不在同一 Docker 网络里，请填写 MediaIndex 容器内可访问的地址，不要填写容器自己的 `127.0.0.1`。

### 1.2 一套 Compose 部署 MediaIndex、PanSou 和 QAS

仓库的 `docker-compose.yaml` 已预留 PanSou 和 QAS 服务，默认被注释。

1. 删除 `pansou` 服务整段每行开头的 `# `。
2. 删除 `quark-auto-save` 服务整段每行开头的 `# `。
3. 修改 MediaIndex 的 `MEDIA_PASS` 和 QAS 的 `WEBUI_PASSWORD`。
4. 执行：

   ```bash
   docker compose up -d
   ```

5. 默认入口：

   | 服务 | 默认地址 | 用途 |
   | --- | --- | --- |
   | MediaIndex | `http://NAS_IP:38000` | 主控制台 |
   | QAS | `http://NAS_IP:5005` | 夸克 Cookie、转存和 API Token |
   | PanSou | `http://NAS_IP:8888` | 资源搜索 API |

同套 Compose 内，MediaIndex 默认访问 `http://quark-auto-save:5005` 和 `http://pansou:8888`，一般不用改成 NAS IP。

## 2. 首次配置

进入 **设置 → 基础设置** 后，建议按这个顺序配置。

### 2.1 通用服务

- **TMDB API Key**：用于搜索媒体、读取季集、播出日期、海报和简介。
- **PanSou 地址**：用于搜索网盘资源。MediaIndex 会生成多关键词搜索策略，再从结果里挑可验证的候选。
- **网络代理**：如果 TMDB 或 PanSou 需要代理，在 **设置 → 网络代理** 填写 HTTP/HTTPS 代理。

保存后使用页面里的测试按钮确认连接正常。

### 2.2 夸克 QAS

1. 登录 QAS。
2. 在 QAS 中配置并验证夸克 Cookie。
3. 在 QAS 页面找到 **API → Token** 并复制。
4. 回到 MediaIndex 的 **设置 → 基础设置 → 夸克**，填写 QAS 地址和 Token。
5. 点击“测试连接”。

QAS Token 会随 QAS 登录信息变化。修改 QAS 管理密码或 Token 后，需要重新复制并更新 MediaIndex。

### 2.3 原生 115

MediaIndex 原生支持 115 分享读取、文件匹配、转存、改名、移动和目标目录确认，不要求 MoviePilot 执行转存。

1. 进入 **设置 → 基础设置 → 115**。
2. 粘贴包含 `UID`、`CID`、`SEID` 的 115 Cookie。
3. 或填写 MoviePilot 后端地址和 API Key，从 `P115StrmHelper` 插件安全导入 Cookie。
4. 填写 115 保存根目录、115 网盘暂存目录和 115 转存本地目录。
5. 点击“测试连接”。

115 的 **网盘暂存目录** 位于 115 网盘内，用于先接收、核对、改名，再移动到最终目录。它不是 NAS 本地目录。

115 的 **转存本地目录** 用于“存本地”工作流，需要挂载进 MediaIndex 容器。默认 Compose 使用 `./downloads:/downloads`。

Cookie 是完整账号凭据，只保存在服务端数据目录的 `.env` 中，配置接口不会返回 Cookie。不要截图、转发或提交到 Git。

### 2.4 保存路径、分类路径和命名

夸克和 115 有独立的保存根路径与分类路径。分类路径支持：

- 电影
- 电视剧
- 综艺
- 演唱会
- 纪录片
- 动漫
- 自定义分类

分类路径右侧的文件夹按钮会直接使用当前 Provider 的凭据读取目录：

- 夸克：通过 QAS Token 读取目录。
- 115：通过 115 Cookie 读取目录。

命名规则位于 **设置 → 基础设置 → 命名与分季**：

- 媒体文件夹命名规则，例如 `{title} ({year})`
- 季文件夹命名规则，例如 `Season {season}` 或 `S{season:02d}`
- 电影文件命名规则，例如 `{title}.{year}`
- 剧集文件命名规则，例如 `{title}.{year}.S{season:02d}E{episode:02d}`

开启“剧集按季分目录”后，新任务会保存到媒体目录下的季目录；旧任务路径仍保持兼容识别。

## 3. 发现、搜索和转存

### 3.1 发现页

发现页从 TMDB 获取电影、剧集、综艺、演唱会、纪录片和动漫。卡片支持：

- 打开详情。
- 刷新资源状态。
- 加入智能追更。
- 选择单个网盘转存。
- 一键转存所有有资源的网盘。

如果某个资源只有夸克或只有 115，MediaIndex 会只转存有资源的一边。开启 OpenList 自动同步后，转存完成会按配置的方向尝试补齐目标网盘。

### 3.2 单次转存流程

1. 选择媒体和季。
2. MediaIndex 先用 PanSou 搜索候选分享。
3. 标准电影若能从 PanSou 标题、年份和真实文件唯一确认，会跳过 TMDB 直接生成转存任务；其他情况再用 TMDB 匹配规范媒体信息。
4. QAS 或 115 Provider 读取分享内真实文件。
5. 综艺匹配标题、年份、季、期数和文件类型；电影、电视剧主要核对名称、年份和季集标记。
6. 证据足够时自动转存并按命名规则重命名。
7. 证据不足时进入 **待确认**。

剧集和电影如果能从文件名、标题和季集结构直接确认，就不额外做复杂核验；其中标准电影还可以在 PanSou 阶段跳过 TMDB。综艺命名常包含“第几期”“上/下”“纯享版”等不稳定信息，会更依赖 TMDB 日期和期数信息做保守判断。

### 3.3 多季转存

多季剧集可以同时选择多个季。MediaIndex 会按 `Provider × Season` 建立独立子任务：

- 前面已完结季优先寻找完整包。
- 如果完整包中只有部分文件符合要求，会先转存可确认的部分，再继续寻找缺失内容。
- 最后一季可以作为追更季处理。
- 一个 Provider 失败不会回滚另一个 Provider 的成功结果。

## 4. 智能追更

智能追更的核心逻辑是：**每次执行都读取目标网盘目录的真实状态，再决定从哪里开始追。**

### 4.1 创建追更

在发现卡片或详情弹窗中点击 **加入智能追更**，选择季和目标网盘。正在连载的剧集或综艺会默认加入追更。已经加入追更的季仍可手动转存。

### 4.2 自动执行规则

到达设定时间后，MediaIndex 会：

1. 刷新 TMDB 季集信息。
2. 读取目标网盘目录中实际存在的文件。
3. 识别已存集数。
4. 从最后一集的下一集开始搜索。
5. 只有目录一集都没有时，才按初始全量资源处理。

历史缺集不会被自动回头补，除非你手动勾选缺失集并点击 **补齐所选**。这样可以避免日常追更反复搜索早期旧资源。

### 4.3 卡片状态

智能追更卡片会显示：

- 当前运行状态。
- TMDB 已播集数。
- 夸克和 115 已确认集数。
- 下次巡检时间。
- 近期执行消息。
- 每个网盘每一集的已存、缺失和未来状态。

点击刷新时，系统会重新读取网盘真实目录，不继承历史缓存作为最终状态。

## 5. OpenList 自动同步

OpenList 用于已挂载的夸克媒体库和 115 媒体库之间复制文件。它不替代 QAS 或 115 原生转存，只负责两边文件补齐。

### 5.1 启用

进入 **设置 → OpenList 同步**：

1. 启用 OpenList 功能。
2. 填写 OpenList 地址和 Token。
3. 选择夸克媒体库目录和 115 媒体库目录。
4. 开启“允许自动同步”。
5. 选择自动同步方向；115 是主媒体库时建议选择“夸克 → 115”。

OpenList 同步路径使用 OpenList Token。分类路径和通知下载路径优先使用 QAS/115 原生凭据；115 Open 直连不可用时，会通过 OpenList 中该 115 存储的实际挂载点读取目录。

### 5.2 自动同步较新资源

当链接/卡片转存完成、智能追更或愿望单巡检补到新集，或用户手动发起同步时，MediaIndex 会对比两边目录：

- 只同步缺少的一边。
- 目标媒体目录不存在时，复制已经由 QAS 改好名的整个媒体或 Season 文件夹；目标目录存在时只复制缺失文件，并跳过同名文件。
- 相同目录已有同步任务在运行时，不重复触发。
- 任务会显示在右上角执行任务窗口。
- 自动同步由上述业务事件触发，不会每隔若干秒轮询或递归扫描整个媒体库。
- 自动同步可选夸克 → 115、115 → 夸克或双向。该设置只约束自动触发；手动同步和追更卡片中的手动补齐不受限制。
- 多网盘同时搜索时，只要同季度已有一个网盘成功，且自动同步已管理这对网盘，就不会为另一侧的“无资源”结果建立愿望单。

智能追更卡片中，如果后台检测到某个网盘正在自动同步，会显示“自动同步中”的转圈状态。

### 5.3 手动同步

进入 **设置 → OpenList 同步 → 手动同步**：

- 左右两边分别浏览夸克媒体库和 115 媒体库。
- 点击目录名进入文件夹。
- 勾选文件后可向另一边复制。
- 可选择跳过已存在或覆盖已存在。
- 支持按文件名、类型和时间排序，重复点击切换正序/倒序。

## 6. 待确认

待确认代表系统已找到可能资源，但不能安全自动执行。处理建议：

- 先看候选标题、年份、季和来源。
- 再看分享中的真实文件。
- 可以只勾选确定的文件继续转存。
- 明显不相关的候选可以删除或重新搜索。

企业微信自建应用启用交互回调后，或 Telegram Bot 配置允许的 Chat ID 后，待确认任务也可以在手机端回复编号或使用 Telegram 按钮处理。

## 7. 愿望单

愿望单适合还未开播、资源尚未出现或暂时找不到的媒体。

- 按 TMDB 日期和全局设置的小时巡检。
- 可切换目标网盘。
- 可手动点击立即执行。
- 进入待确认后可在网页、企业微信或 Telegram 中选择候选。

## 8. 通知和交互

网页内通知显示在右上角小铃铛。外部通知位于 **设置 → 通知设置**，支持：

- 企业微信自建应用。
- 企业微信群机器人。
- Telegram。

配置公网访问地址后，外部通知会优先发送带海报的图文消息；失败时回退为文字。

### 8.1 企业微信自建应用

填写：

- 企业 ID（CorpId）
- 应用 Secret
- AgentId
- 接收成员、部门或标签
- 企业微信 API 地址

保存后点击测试按钮。

### 8.2 企业微信交互回调

填写：

- 回调 Token
- EncodingAESKey
- 允许指令的成员 UserID

页面会生成企业微信后台需要填写的回调 URL。企业微信后台、MediaIndex 和应用可见范围要保持一致。

### 8.3 Telegram 交互

启用 Telegram，填写 Bot Token 和允许交互的 Chat ID。MediaIndex 通过 Bot API 轮询消息；只有配置列表中的 Chat ID 可以触发搜索、转存、编号确认和按钮操作。Telegram 与企业微信自建应用共用下面的指令和交互设置，企业微信群机器人仅发送通知。

### 8.4 可用指令

| 消息或指令 | 功能 |
| --- | --- |
| `资源名` | 搜索影视并默认保存到网盘；多个匹配时返回编号 |
| `本地 资源名` | 搜索影视并保存到本地 |
| `分享链接` | 夸克或 115 分享链接直接转存到默认路径 |
| `磁力链接` | 固定提交到 115 离线下载 |
| `1`、`2` 等数字 | 确认当前资源、待确认任务或候选 |
| `/review` | 查看待确认任务 |
| `/status` | 查看追更、愿望单、待确认和未读通知数量 |
| `/tracking` | 查看最近智能追更任务 |
| `/wishlist` | 查看最近愿望单任务 |
| `/notifications` | 查看最近通知 |
| `/cancel` | 取消当前等待中的编号选择 |
| `/help` | 查看指令帮助 |

编号选择按企业微信 UserID 或 Telegram Chat ID 独立保存，有效期为 30 分钟。

### 8.5 下载链接自动转存

在 **设置 → 通知和交互 → 交互指令** 中启用 **下载链接自动转存**。该设置同时作用于企业微信自建应用和 Telegram。

可设置：

- 参与交互的网盘：夸克和 115 可同时勾选；资源名会对已勾选网盘发起转存。
- 磁力/电驴默认网盘固定为 115；分享链接仍按链接类型选择对应网盘。
- 默认保存路径。

默认保存路径右侧的“选择路径”按钮会根据关联网盘读取目录：

- 夸克：通过 QAS Token 读取目录。
- 115：使用 Cookie 或 115 Open 凭据读取目录；115 Open 直连不可用时会通过 OpenList 对应存储读取。

支持范围：

- 夸克分享链接：选择夸克或系统识别为夸克链接时，由 QAS 转存。
- 115 分享链接：选择 115 或系统识别为 115 链接时，由原生 115 转存，需配置有效 Cookie。
- 磁力、ed2k、HTTP/HTTPS 下载链接：固定提交到 115 的默认保存路径；可使用 115 Open，直连不可用时通过 OpenList 的 115 Cloud 提交。

115 离线下载提交后，MediaIndex 会短时间查询 115 任务状态：如果 115 已经秒存完成，会返回“115 云下载完成”；如果 115 明确失败，会返回 115 提供的失败原因；如果 115 仍在处理，会提示任务已提交且仍在处理中。长时间下载进度以 115 客户端或 115 网页端的离线下载任务列表为准。

## 9. 更新、备份和恢复

更新：

```bash
docker compose pull
docker compose up -d
```

备份前停止服务，然后备份：

- `./data`：MediaIndex 配置、SQLite 数据库和缓存。
- `./quark-auto-save/config`：QAS Cookie、任务和配置。
- `./downloads`：如果你使用 115 本地下载目录。

恢复时把备份目录和 `docker-compose.yaml` 放回同一部署目录，再执行 `docker compose up -d`。

## 10. 常见问题

### MediaIndex 显示 QAS 未配置

确认 QAS 地址和 Token 都已保存。只有地址没有 Token 时，QAS 会保持未配置状态。

### 115 测试连接失败

确认 Cookie 包含 `UID`、`CID`、`SEID`，且没有换行。Cookie 过期后需要重新获取。

### 容器之间无法连接

同套 Compose 要让 MediaIndex、PanSou 和 QAS 都在同一个 Docker 网络。独立部署时，填写 MediaIndex 容器内可访问的服务地址。

### 修改 QAS 密码后转存失败

重新登录 QAS，复制新的 API Token，再到 MediaIndex 中保存。

### 智能追更刷新后集数不对

先确认对应网盘的实际目录是否存在，路径是否符合当前分类路径和命名规则。刷新会直接读取网盘真实目录；如果目录名称不标准，系统会尝试宽松匹配，但仍建议统一使用 MediaIndex 的命名规则。

### 磁力链接不能提交

确认通知设置中已经启用“下载链接自动转存”，并且 115 Cookie 或 115 Open 凭据有效。夸克当前不支持磁力离线下载。

## 11. 安全提示

- MediaIndex、QAS 和反向代理都应使用强密码。
- TMDB Key、QAS Token、115 Cookie、OpenList Token 和通知凭据都不得提交到 Git。
- 建议仅在内网、VPN 或可信 HTTPS 反向代理后使用。
- 本项目不提供任何资源、Cookie 或网盘账号，使用者需自行确保使用行为合法合规。
