## Compatibility

- Behavior changed: Yes，具体行为如下。
- Database changed: No，复用任务状态 JSON，无数据库迁移。

## 行为变化

1. **发现页 115 资源**：收集 PanSou 原生分享和磁力结果。先核验原生分享，失效时选择标题、年份及季度符合要求的磁力，再按已有质量关键词排序。PanSou 查询仍只使用片名；年份、季度和质量用于本地匹配，不拼进搜索词。资源弹窗区分网盘分享与磁力云下载。原生转存已经产生部分结果时不自动回退，避免重复写入。
2. **媒体身份与整理**：磁力提交沿用发现页原任务及 TMDB 身份，通过实际配置的云下载分类目录暂存。发现页已确认的单个正片可按片名、年份生成命名计划；企微/TG 未提供名称时，从实际文件名去除前置站点标签、扩展名和发行规格，提取标题与年份。唯一准确的 TMDB 标题/原名加年份命中避免逐个详情查询，标准片名查询使用缓存。多个无法证明属于同一影片的视频仍进入人工核对。
3. **完成状态核验**：识别 115 的 `percentDone`、`display_status` 等返回字段；按任务 ID/哈希匹配，避免误用别的已完成记录。整理前核验本次暂存路径、文件名及返回文件 ID 的归属；找不到实际目标时进入待核对。轮询和立即完成复用同一核验流程，记录轮询时间、次数、结果和错误。
4. **诊断能力**：临时令牌可读取运行概况、按名称查任务、查看时间线、实时核验指定 115 下载记录及其目录、下载完整诊断包。实时核验限定为只读操作，路径来自已有任务，目录返回最多 100 项，同任务至少间隔 30 秒。令牌不提供命令执行入口；导出和接口过滤凭据、分享 URL 与未审核的原始响应。
